# Static site with reviewed data releases

Use a static public website with income and place-search data prepared before deployment, rather than a live application server and database. Historical census data and reviewed updates do not require per-visit source queries, and a static architecture supports the initial $0/month operating target. The trade-off is that data changes require a new validated build and deployment, and browser-delivered datasets must remain practical for mobile use; hosting and basemap services still need separate evaluation.
