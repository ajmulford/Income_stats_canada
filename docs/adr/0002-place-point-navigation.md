# Use reviewed place points for initial resident navigation

For the first HRM release, search the 364 GeoSuite place records from the reviewed source snapshot. Use each record's verified coordinates and its validated containing dissemination area. Preserve duplicate names as separate choices, distinguishing them with a direction relative to the other source point, coordinates, and the containing area identifier. Normalize case, whitespace, accents, and punctuation for matching. The reviewed source records contain no verified aliases; do not invent neighbourhood names or alternate-name equivalences.

The HRM civic-community inventory contains valid current polygons, but its metadata warns that some boundaries await consultation and does not provide a dependable finality classification for every feature. Geometry validity and a blank remarks field do not certify a boundary as reliable. Use the already agreed point fallback consistently instead of enabling intersecting-area navigation from this inventory. No community-wide income is calculated.

An uncontained or multiply contained point is shown on the map with an explicit explanation and no assigned income. The complete census-area list remains available. A future reviewed boundary source or per-community reliability assessment can enable intersecting-area navigation without changing the income measure or census geometry.
